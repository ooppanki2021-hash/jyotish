# Джйотиш — ведический астролог (личный сайт)

Точный расчёт ведической натальной карты (сидерический зодиак, аянамша Лахири) прямо в браузере + генерация чтения + прогностика (Вишоттари-даша, транзиты) + совместимость (аштакота-гун-милан) + **ИИ-астролог** (чат на базе Google Gemini).

Всё работает **без сервера** — только статические файлы. Идеально для GitHub Pages.

---

## Что умеет

- **Карта и чтение** — по дате/времени/месту рождения: Лагна, положения планет (знак, градус, дом, накшатра, пада), статусы (экзальтация, сожжение, ретроградность). Подробный разбор 11 разделов: портрет (с выдающимися положениями), сильные стороны, сложности, призвание (с Д-10), деньги (с дхана-йогами), отношения, здоровье, спорт, семья, образование, **упайи (мантры, дана, камни)**. Каждый раздел: кратко + «💡 простыми словами» + «читать подробно» + словарь терминов.
- **Прогностика** — Вишоттари-махадаша, под-периоды (антарадаша), текущие транзиты Сатурна/Юпитера/Раху/Кету + **годовой прогноз (варшапхал)**: солнечное возвращение, мунтха, управитель года.
- **Совместимость** — классические 36 баллов (аштакота) + **глубокая синастрия**: мангала-доша, 7-й дом, Венера, наложение домов, навамша.
- **Мухурта** — выбор благоприятного времени: панчанга на сегодня (титхи, вара, накшатра, Раху-кала) + поиск удачных окон для дел (брак, бизнес, недвижимость, поездки и др.).
- **Печать / сохранение** — разбор в виде PDF (через печать) или автономного HTML-файла.
- **ИИ-чат** — задавайте любые дополнительные вопросы по своей карте.

## Технологии

- **Astronomy Engine** (MIT, Дон Кросс) — эфемериды планет с точностью до угловой минуты.
- Расчёт на **чистом JavaScript**, без сборки и зависимостей на этапе запуска.

## Как опубликовать на GitHub Pages (бесплатно, домен не нужен)

1. Создайте аккаунт на [github.com](https://github.com) (если ещё нет).
2. Нажмите **New repository**, назовите, например, `jyotish`.
3. Загрузите **содержимое этой папки** в репозиторий (все файлы, включая `js/`, `index.html`, `style.css`, `README.md`).
   - Можно просто перетащить файлы в веб-интерфейс GitHub, либо через `git`.
4. **ВАЖНО: репозиторий должен быть публичным (Public).** На бесплатном тарифе GitHub опция «Deploy from a branch» (развёртывание из ветки) доступна **только для публичных репозиториев**. Если репозиторий приватный — этой настройки в меню просто не будет видно. (В коде нет секретов: API-ключ хранится только в браузере, так что публичность безопасна.)
5. В репозитории откройте **Settings → Pages**.
6. В разделе **Build and deployment** → Source выберите **Deploy from a branch**, ветку **main** (или master), папку **/ (root)**.
7. Сохраните. Через 1–2 минуты сайт будет доступен по адресу:
   ```
   https://ВАШ_ЛОГИН.github.io/jyotish/
   ```

> **Если пункта «Deploy from a branch» не видно** — почти всегда причина в том, что репозиторий **приватный** (см. п.4). Сделайте его Public: **Settings → General → Danger Zone → Change repository visibility → Public**. После этого настройка появится.
>
> **Если опция есть, но кнопка «не нажимается»:** переключите Source на «GitHub Actions» и обратно на «Deploy from a branch» — интерфейс «оживёт» и предложит выбрать ветку `main`.

Домен покупать не нужно. Для личного пользования этого достаточно.

> Если хотите, чтобы сайт открывался по `https://ВАШ_ЛОГИН.github.io/` (без `/jyotish`), назовите репозиторий `ВАШ_ЛОГИН.github.io`.

## Как включить ИИ-астролога

Чат работает через API одного из сервисов. На вкладке **«Спросить астролога»** выберите провайдера, вставьте ключ и нажмите **Сохранить**.

Ключ хранится **только в вашем браузере** (localStorage) и **не попадает** в код и репозиторий. Он отправляется только напрямую в выбранный сервис при запросе.

### ⭐ Вариант 1 — Cloudflare Workers AI (бесплатно, проще всего)
Самый простой бесплатный вариант: нужен **только аккаунт Cloudflare** (бесплатно), без ключей, без оплаты и без сторонних сервисов. Бесплатный лимит — 10 000 токенов/день (для личного чата достаточно).

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/).
2. **Workers & Pages → Create → Create Worker** → имя (например `astro-ai`) → **Deploy**.
3. **Edit code** → вставьте целиком код из файла `cloudflare-ai-worker.js` → **Deploy**.
4. Добавьте привязку ИИ: в настройках Worker найдите **Bindings** → добавьте binding типа **AI** с именем `AI`.
5. Скопируйте адрес Worker (вида `https://astro-ai.ВАШ-ЛОГИН.workers.dev`).
6. На сайте: вкладка «Спросить астролога» → провайдер **Cloudflare** → в поле **Base URL** вставьте адрес Worker → поле «API-ключ» оставьте пустым → **Сохранить**.

Модель по умолчанию `@cf/meta/llama-3.1-8b-instruct`. Можно заменить на `@cf/meta/llama-3.2-3b-instruct` (быстрее) или `@cf/deepseek-ai/deepseek-r1-distill-qwen-32b` (умнее).

### Вариант 2 — GigaChat от Сбера (бесплатно, работает в РФ)
GigaChat даёт **1 млн токенов в месяц бесплатно**. Из-за особенностей авторизации нужен крошечный бесплатный посредник (Cloudflare Worker) — код уже готов в файле `gigachat-worker.js`.

1. Получите ключи GigaChat: зарегистрируйтесь на [developers.sber.ru](https://developers.sber.ru/) (или smartspeech.sber.ru), создайте проект **GigaChat API**, в настройках нажмите «Получить ключ» — получите **Client ID** и **Client Secret**.
2. Создайте бесплатный Worker: на [dash.cloudflare.com](https://dash.cloudflare.com/) → **Workers & Pages → Create → Create Worker** → имя (например `gigachat-proxy`) → **Deploy** → **Edit code**.
3. Вставьте целиком код из файла `gigachat-worker.js`, нажмите **Deploy**.
4. В настройках Worker: **Settings → Variables** → добавьте две переменные `GIGACHAT_CLIENT_ID` и `GIGACHAT_CLIENT_SECRET` (значения из шага 1).
5. Скопируйте адрес Worker (вида `https://gigachat-proxy.ВАШ-ЛОГИН.workers.dev`).
6. На сайте: вкладка «Спросить астролога» → провайдер **GigaChat** → в поле **Base URL** вставьте адрес Worker → поле «API-ключ» можно оставить пустым → **Сохранить**.

### Вариант 3 — DeepSeek (⚠️ требуется небольшой баланс)
1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com/).
2. **API keys → Create** — ключ вида `sk-...`.
3. На сайте выберите **DeepSeek**, вставьте ключ.
4. Модель `deepseek-chat`. Очень дёшево, но нужно пополнить баланс (оплата из РФ может быть затруднена).

### Вариант 4 — OpenRouter (⚠️ с 2026 г. ограничен для РФ)
1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai/).
2. **Keys → Create Key** — ключ вида `sk-or-...`.
> ⚠️ С мая–июля 2026 OpenRouter ограничивает пользователей из России (в т.ч. выдачу ключей).

### Вариант 5 — Groq (⚠️ может быть ограничен для РФ)
1. Зарегистрируйтесь на [console.groq.com](https://console.groq.com/).
2. **API Keys → Create API Key** — ключ вида `gsk_...`.

### Вариант 6 — Google Gemini (⚠️ недоступен в РФ)
1. [Google AI Studio](https://aistudio.google.com/) → **Get API key** → `gemini-2.5-flash`.

### Вариант 7 — любой OpenAI-совместимый сервис
Выберите «Другой», укажите Base URL (например `https://api.deepseek.com`) и свою модель.

## Приватность и ограничения

- Все расчёты выполняются **локально в браузере** — данные рождения никуда не отправляются.
- Единственное внешнее соединение — чат с Gemini (если введён ключ).
- Джйотиш — традиционная система самопознания, **не точная наука**. Сайт не даёт медицинских, юридических и финансовых советов. За здоровьем — к врачу, за деньгами — к расчёту.
